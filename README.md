# voice-family-phone-privacy

Public privacy policy and legal information for **Family Phone (Családi Telefon)**.

## Public pages

- English privacy policy: `privacy-policy.html`
- Hungarian privacy policy: `privacy-policy-hu.html`
- Language selector: `index.html`

This repository is intended to be published with **GitHub Pages** and used as the public privacy-policy website for the Google Play listing of Family Phone (`org.voicefamilyphone.app`).

The application source code remains in a separate private repository.
